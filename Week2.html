Vectors

  • Make a simple vector, then check structure and typeof:
x <- c(1, 2, 3, 4, sqrt(2))
x
[1] 1.000000 2.000000 3.000000 4.000000 1.414214
str(x)
 num [1:5] 1 2 3 4 1.41
typeof(x)
[1] "double"
  • Make a vector of strings, then check structure and typeof:
y <- c("fish", "chicken", "beef")
y
[1] "fish"    "chicken" "beef"   
str(y)
 chr [1:3] "fish" "chicken" "beef"
typeof(y)
[1] "character"

z <- c(x,y)
z

[1] "character"

Note how the vector change (coerces) all elements to type “character”

  • Use seq() and its shortcuts to create vectors
seq(from = 1, to = 6, by = 2) # from 1 to 6, counting by 2
[1] 1 3 5
seq(1, 6, 2) # same thing
[1] 1 3 5
seq(1, 4, length=5) # vector length 5, starting at 1 and ending at 4, evenly spaced
[1] 1.00 1.75 2.50 3.25 4.00
seq(0, 100, length = 6) # 0 to 100 in 6 steps
[1]   0  20  40  60  80 100
0:6 # shortcut for counting 0 to 6
[1] 0 1 2 3 4 5 6
0:6*20 # scaling the shortcut by multiplication
[1]   0  20  40  60  80 100 120
  • Use runif() (“random uniform number generator”) to make a vector of random numbers.

  • Factor vectors are created with factor() and are used when the elements are categorical data
pets <- c("cat", "dog", "bird", "cat", "other", "bird", "bird", "other", "dog") # our data for pets as a list of categorical observations
pets_factor <- factor(pets, levels = c("cat", "dog", "bird", "rodent", "other")) # associates the defined categorical levels with the pets data
pets_factor
[1] cat   dog   bird  cat   other bird  bird  other dog  
Levels: cat dog bird rodent other
str(pets_factor) # reveals that factors store values as integers, each associated with a level
 Factor w/ 5 levels "cat","dog","bird",..: 1 2 3 1 5 3 3 5 2
  • Levels need to align with the values in the data but we can use Labels to have different values show
pets_factor <- factor(pets,
               levels = c("cat", "dog", "bird", "rodent", "other"),
               labels = c("Meow", "Woof", "Tweet", "Sniff", "zzzzz"))
pets_factor
[1] Meow  Woof  Tweet Meow  zzzzz Tweet Tweet zzzzz Woof 
Levels: Meow Woof Tweet Sniff zzzzz
  • as.factor() is a shortcut to convert to factor vector, but only uses the levels visible
pets_factor <- as.factor(pets) # makes factor vector from all levels observed in pets
pets_factor # notice rodent gets skipped
[1] cat   dog   bird  cat   other bird  bird  other dog  
Levels: bird cat dog other
levels(pets_factor) <- c(levels(pets_factor), "rodent") # here rodent is manually added in afterwards
pets_factor
[1] cat   dog   bird  cat   other bird  bird  other dog  
Levels: bird cat dog other rodent

Matrices

  • Matrices are homogenous, containing vectors of the same type and length. Each column of the matrix is a vector. We can also think of matrix as a long vector we give dimensions to

  • Create a matrix

matrix(data = NA, 
       nrow = 1, 
       ncol = 1, 
       byrow = FALSE,
       dimnames = NULL) # syntax
     [,1]
[1,]   NA
my_mat <- matrix (c(1,3,4,-1,5,6),
                  nrow = 3,)  # If only nrow is provided, ncol is inferred
my_mat # note how data fills the colummns one at a time, but this can be changed with byrow.
     [,1] [,2]
[1,]    1   -1
[2,]    3    5
[3,]    4    6
  • Coerce the matrix back into a vector
as.vector(my_mat)
[1]  1  3  4 -1  5  6
  • If we under-fill a matrix with not enough data, we’ll get a warning and the data repeats

Data Frames

  • A data frame is a list of vectors of the same length. The vectors can be different types.
  • Create a data frame using the data.frame() function
x <- c("a", "b", "c", "d", "e", "f")
y <- c(1, 3, 4, -1, 5, 6)
z <- 10:15
my_df <- data.frame(x, y, z) # combines three equal length vectors of different types
my_df
  x  y  z
1 a  1 10
2 b  3 11
3 c  4 12
4 d -1 13
5 e  5 14
6 f  6 15
  • Data frames take on the column names of the variables we use, but we can also set the names as we create the dataframe
my_df <- data.frame(char = x, data1 = y, data2 = z)
my_df
  char data1 data2
1    a     1    10
2    b     3    11
3    c     4    12
4    d    -1    13
5    e     5    14
6    f     6    15
  • We can access elements of a data frame just like a matrix
iris[1:4, 2:4] #returns a data frame
